# Mahmoud UI

وحدة LSPosed وتطبيق إعدادات صغيران للتحكم بمنزلق واحد لقوة تمويه مركز التحكم الأصلي. القيمة نفسها للدارك واللايت. لا يُستبدل مركز التحكم ولا تُعدّل الألوان أو الشفافية أو التخطيط عمدًا.

## التحكم والحفظ

المنزلق من 1٪ إلى 100٪: 20٪ خفيف، و50٪ متوسط، و100٪ أقصى مستوى. بعد إفلات المنزلق يحفظ التطبيق القيمة عبر `su` باستخدام root، ثم يقرأها ثانية بواسطة `settings get` للتحقق. إذا رُفض طلب الروت أو لم تطابق القراءة القيمة، يعرض التطبيق فشل الحفظ بدل ادعاء النجاح. لا يُشغّل طلب الروت مع كل حركة؛ يحصل الحفظ بعد إفلات المنزلق فقط. في أول حفظ، وافق على مطالبة مدير الروت بمنح الصلاحية لـMahmuod UI.

القيمة مخزنة في `Settings.System` تحت `mahmuod_ui_blur_strength_v2`. يقرأ hook القيمة نفسها ويحدّثها مع تخزين مؤقت قصير، ويضرب نصف قطر البلور بها كنسبة من قيمة النظام. إذا لم تكن نقطة الربط متاحة، تترك الوحدة SystemUI دون تعديل.

## التفعيل والتراجع

ثبّت APK، افتح التطبيق، حرّك المنزلق ثم أفلت ووافق على طلب الروت. فعّل Mahmuod UI في LSPosed على **System UI فقط** وأعد تشغيل SystemUI أو الهاتف. للتراجع، اضبط المستوى إلى 100٪ أو عطّل الوحدة. إذا استمر فشل الحفظ، افحص سجل طلبات مدير الروت وتأكد أن صلاحية Mahmuod UI لم تُرفض.

## البناء والحدود

يُبنى المشروع عبر `./gradlew assembleDebug` مع Android SDK Platform 35 وJDK 17+. نقطة الربط هي `com.android.systemui.blur.QSColorCurve.setFraction(float)` استنادًا إلى APK المرجعي. نجح التجميع والفحص الساكن، لكن لم يختبر على Galaxy M34 فعليًا. إذا لم يتغير البلور أو حدث كراش، عطّل الوحدة وأعد تشغيل SystemUI.

## واجهة One UI 9 (v0.6.0)

أُعيد تصميم شاشة التطبيق بأسلوب One UI 9: عنوان كبير في أعلى الصفحة، بطاقات مستديرة (٢٨dp)، عداد كبير للقيمة مع زرّي + و− (الضغط المطوّل يكرّر)، منزلق سميك بشكل حبة مع مقبض أبيض واهتزاز خفيف كل ٥٪، وأزرار جاهزة للقيم ٢٠٪ و٥٠٪ و١٠٠٪. تتبع الواجهة وضع النظام (فاتح/داكن) وتدعم العرض الكامل للشاشة. الحفظ بالروت بعد إفلات المنزلق، أو بعد ٠٫٤٥ ثانية من آخر ضغطة على + أو − أو أحد الأزرار الجاهزة. منطق البلور في `BlurRestoreHook` لم يتغير. أُضيفت أيقونة التطبيق (`drawable/mahmoud_ui_icon`) واسم التطبيق صار Mahmoud UI.
